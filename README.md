Como Jogar no VS Code (Sem comandos)

1. Abra o arquivo batalha_naval.py no VS Code.
2. Clique no botão de Play (o triângulo ▶) no canto superior direito.
3. O jogo vai rodar sozinho na parte de baixo da tela.
Regras do Jogo

* Tabuleiro em matriz tamanho 5x5.
* Cada jogador tem 5 navios escondidos em posições fixas no código.
* Digite Linha (1 a 5) e Coluna (1 a 5) para atirar.
* X significa que acertou o navio e O significa água.
* Vence quem acertar os 5 navios primeiro.

Recursos do Jogo

* Validação de entradas (não quebra com letras, espaços ou campos vazios).
* Desafio de lógica: Mostra o placar, histórico, porcentagem de vitórias e a maior sequência de vitórias ao sair.
